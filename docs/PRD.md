# LocalNote 产品需求文档（MVP v0.1）

## 1. 产品概述

LocalNote 是一款面向个人的本地优先富文本笔记桌面应用。所有正文、图片和索引均保存在用户设备的 `Documents/LocalNote` 中，不需要账号、服务器或联网同步。

**目标用户**：在意隐私、希望按目录和标签沉淀知识的个人创作者与知识工作者。

**核心价值**：私有可控的数据、专注且顺滑的写作体验、轻量但足够的文档管理能力。

## 2. MVP 范围

| 模块 | 首版能力 | 验收标准 |
| --- | --- | --- |
| 工作台 | 最近文档、横向列表/纵向卡片切换、搜索、新建、右键删除 | 可按标题、标签和摘要筛选；删除需二次确认；展示偏好在本机保留 |
| 编辑器 | 标题、粗体/斜体、标题层级、列表、引用、代码块、分割线、图片、手写画板 | 格式和手写内容可编辑，关闭重开后保留 |
| 组织 | 文件夹创建、目录展示、用户自定义标签、标签删除 | 文件夹可创建；打开文档时侧栏展示其标签；标签删除会从关联文档移除 |
| 存储 | JSON 正文、索引、图片缓存 | 无网络情况下可读写；数据目录可手动备份 |
| 保存 | 新文档显式保存、已有文档自动保存、Ctrl/Cmd + S | 未确认保存的新文档不进入索引；已有文档停止编辑 900ms 后写盘 |

## 3. 关键交互

启动后先显示工作台；点击“新建文档”进入内存草稿，只有点击保存或按 Ctrl/Cmd+S 后才加入文档索引。离开未保存草稿时，应用提供保存、放弃和继续编辑三种选择。已存在的文档在用户停止输入后静默保存。用户可切换横向列表或纵向卡片视图；目录通过非阻塞对话框创建。插入图片时，应用复制原文件到本地 `assets` 目录，并通过应用专用只读协议展示。手写画板支持鼠标、触摸和压感笔输入，完成后导出为本地 PNG 资源插入当前文档。

## 4. 数据与隐私

数据根目录为 `Documents/LocalNote`：

```text
LocalNote/
  index.json       # 文档元数据、目录结构
  docs/<id>.json   # Tiptap JSON 正文
  assets/<time>.*  # 应用托管的图片
```

`index.json` 中的文档包含 `id`、`title`、`filePath`、`tags`、`parentId`、`createdAt`、`updatedAt`。应用通过 Electron preload 暴露受限 IPC 接口；渲染进程不启用 Node.js，避免编辑器页面取得完整文件系统权限。

## 5. 非目标与后续迭代

MVP 不含云同步、账号、多端协作、全文正文索引、导入导出和拖拽移动。v0.2 优先补齐标签编辑、文件夹拖拽、删除/回收站与正文全文检索；v0.3 再评估加密备份与跨端同步。

## 6. 技术方案

- Electron 主进程负责窗口、文件系统和图片复制。
- Vue 3 + Vite 渲染工作台和编辑器界面。
- Tiptap（ProseMirror）负责结构化富文本，正文序列化为 JSON。
- `contextIsolation` 开启，所有读写都经由白名单 IPC 方法。

## 7. 运行方式

安装依赖后执行 `npm run dev`。启动脚本会向系统申请一个空闲端口，在该端口启动 Vite，并将实际地址传给 Electron 后打开应用窗口，不依赖固定的 5173 端口。
